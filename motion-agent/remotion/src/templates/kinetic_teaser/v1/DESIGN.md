# 制作指示書: kinetic_teaser v1

> この型を作る・直す時に Claude（Opus 5.5 を推奨）へ渡す指示。型のコードと一緒に版で管理する。
> 新しい型や別チャンネルの型は、このファイルを写して直す（`Docs/OPENING_MOTION_PLAN.md` §3-2）。
> 元にしたイメージコンテ: `Docs/mockups/opening/conte_kinetic_teaser.jpg`（**構成と演出の意図を伝えるもの。中の素材や文言は使わない**）。

## 1. 何を作るか

史実・事件を扱うチャンネルの、話ごとのオープニング（本編の軽い紹介）。20秒以内。
毎話の中身（言葉・素材・白か黒か）は**データとして流し込む**。型は話をまたいで変わらない「チャンネルの顔」。

## 2. 構成（ビート）と演出の意図

| # | ビート | 中身（毎話のデータ） | 演出の意図 |
|---|---|---|---|
| ① | `b1_first` 最初のキーワード | 一番のキーワード、または日付・場所（1〜3個。種類 `word`/`date`/`place`） | 文字が飛び込み、ゆっくり印象的にズーム。種類ごとに見せ方を変える（日付＝数字が落ちて下線が走る、場所＝字間が締まりピンが立つ、単語＝叩きつけと色ずれ） |
| ② | `b2_flow` キーワードの流れ | 概要ナレーションのキーワード3〜6語 | ナレーションの区切りで語が切り替わる。多彩な出方。背景の色が次々変わり、煽る |
| ③ | `b3_montage` 素材のカット | 関連する写真・動画（4〜12個） | 矢継ぎ早のカットイン／飛び込み。**だんだん速くなり**④へなだれ込む |
| ④ | `b4_out` アウト | `white`/`black` | ホワイトアウトかブラックアウト |
| ⑤ | `b5_title` タイトルバック | タイトル板の画像（無ければ文字） | アウトの色から現れ、ゆっくり意味深にズーム |
| ⑥ | （書き出さない） | チャンネル・イメージ・ムービー | DaVinci 側で繋ぐ |

## 3. 守ること（技術の約束）

- **時間は計算しない。** ビートの境界・②の切り替え・③のカット・効果音の打点は、props の `timing`（フレーム）を使う。本籍は Python（`motion-agent/app/core/timing.py`）。音も同じ `timing` から作るので、絵だけ独自に時間を決めると音とずれる。
- **制約の本籍は `meta.json`。** 枠の個数・字数・秒・色の並び・変化のつまみを変える時は `meta.json` を直す（Python の検査と TS の両方がこれを読む）。直したら `python -m app.tools.build_samples` で見本の props を作り直す。
- **決定性。** `Math.random()`・`Date.now()`・CSS アニメーション/トランジションは使わない。揺らぎは `random('固定の種')`、動きは `useCurrentFrame()` から作る。外部 URL へ通信しない（素材は props の `asset_base` と `static/` だけ）。
- **安全域。** 文字は画面幅の90%（1728px）に収める。ズームする要素は、ズームの最大倍率を見込んで `fitSize` の幅を決める（v1 で「PROJECT ZERO」がはみ出した前例）。
- **日本語。** 書体は Noto Sans CJK JP（太字 900）と Noto Serif CJK JP（700）。絵文字は Noto Color Emoji。改行させない（`whiteSpace: nowrap`）・長い語は `fitSize` で縮める。
- **版を壊さない。** 公開済みの版の見た目を変える修正はしない。変えるなら `v2/` を作る（過去の話を描き直しても同じ絵になるように）。
- **確認。** 直したら確認用の静止画（`POST /stills?wait=`）を見る。静止画は同じ入力でバイト一致すること、通しの描画は PSNR 40dB 以上で一致すること（動画素材の取り出しが並列でわずかにずれるため）。

## 4. 変化のつまみ（話ごと・チャンネルごとに選ぶ）

`meta.json` の `variants`: `palette`（crimson・noir・toxic）・`montage_motion`（fly・cut）・`montage_tone`（mono・color）・`grain`（粒子の有無）。
